# Maryum Akram

## Applied AI Engineer

**AI Engineer building reliable ML and LLM systems from evaluation to production.** Full-stack delivery across structured extraction, live-data reasoning, voice workflows, classical ML, security, CI/CD, and deployable product interfaces.

## Selected engineering projects

### Receipt Extractor API

Built a FastAPI document-intelligence service that transforms messy receipt text into validated vendor, date, amount, currency, confidence, and `needs_review` fields. Added provider abstraction, strict timeouts, bounded retries, one repair loop, quarantine handling, background jobs, idempotency, SQLite persistence, PDF reports, prompt-injection testing, Docker, CI, and an 8-case labelled evaluation.

### RoshanAI

Built a career-intelligence system that combines live job ingestion, structured LLM reasoning, skill-gap analysis, and proposal generation. Separated frontend and backend concerns, added authentication and server-side provider boundaries, and documented independent user validation while distinguishing product evidence from unbenchmarked AI-generated estimates.

### MediLens

Designed a voice receptionist workflow that maps caller intent to explicit appointment actions across booking, rescheduling, cancellation, confirmation, and fallback paths. Added a portfolio-safe interactive simulation and documented scripted-flow evaluation rather than claiming unsupported production accuracy.

### SkillSync AI

Built a secure AI career product with authenticated workflows, rate limiting, audit logging, adversarial payload testing, CI validation, and explicit evaluation limitations. Documented 94/94 CI tests, 12 adversarial security payloads, and validation with nine real users.

### Resume Screener

Built a two-stage classical-ML pipeline using TF-IDF, Logistic Regression, Gradient Boosting, and sentence-embedding features. Documented 68.0% category accuracy, suitability MAE 8.69, R² 0.814, model comparisons, a 2,484-resume dataset, and genuine-versus-unrelated job tests. Added reproducible Stage 1 and Stage 2 training scripts, versioned manifests, artifact verification, Docker, and CI smoke checks.
