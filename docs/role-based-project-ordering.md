# Role-based project ordering

Use the same five projects, but change the order and opening sentence for each application.

## Applied AI Engineer / AI Solutions Engineer

**Order:** Receipt Extractor → RoshanAI → SkillSync AI → MediLens → Resume Screener

**Opening:** I build reliable AI systems from evaluation to production, connecting models to secure APIs, live data, human-review paths, and measurable workflows.

## Machine Learning Engineer

**Order:** Resume Screener → Receipt Extractor → RoshanAI → SkillSync AI → MediLens

**Opening:** I build and evaluate ML systems, then package them as reproducible applications with versioned artifacts, APIs, CI checks, and operational safeguards.

## LLM Application Engineer

**Order:** Receipt Extractor → RoshanAI → MediLens → SkillSync AI → Resume Screener

**Opening:** I build structured LLM applications with evaluation cases, validation, bounded repair, fallback behavior, security controls, and production-oriented integrations.

## Conversational AI / Voice AI Engineer

**Order:** MediLens → Receipt Extractor → RoshanAI → SkillSync AI → Resume Screener

**Opening:** I design conversational systems that map user intent to explicit actions, confirm state, handle cancellation or recovery, and fail safely instead of guessing.

## AI Product Engineer

**Order:** SkillSync AI → Receipt Extractor → RoshanAI → MediLens → Resume Screener

**Opening:** I ship full-stack AI products with authenticated workflows, live data, secure backend boundaries, evaluation evidence, and interfaces people can actually use.

## Interview framing

For every project, answer in this order: **problem, system boundary, model or AI decision, evaluation, failure mode, deployment, next limitation**. Do not lead with the tool list. Lead with the user problem and the evidence that the system works.
